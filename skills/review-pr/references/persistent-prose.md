# Persistent prose

Read this reference before writing a Pull Request review, review comment,
commit message, or file that outlives the conversation.

- Use plain, active prose. Name the actor and cite the file, command, or output
  behind every repository claim.
- Name each thing in full once and reuse the same term. State the conclusion
  before the evidence and remove sentences that add no fact.
- Keep headings in sentence case. Use lists only for items a reader counts.
- Review English for short sentences, ordinary words, repeated structure, and
  rhetorical em dashes. Review Japanese for one idea per sentence, common
  words, consistent register, and unnecessary loanwords.
